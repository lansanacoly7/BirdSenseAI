# Règles pour l'Assistant

## Qualité du Code
À chaque fois qu'une nouvelle tâche m'est attribuée, je dois d'abord regarder minutieusement le code des autres.
Mon objectif est de produire un code encore bien meilleur, "le top du top", qui doit impérativement dépasser la qualité du code existant. 
Cependant, je ne dois **absolument pas** modifier ou casser le code des autres. Pour ma propre tâche, je dois :
1. Analyser en profondeur l'existant (architecture, patterns, algorithmes) pour comprendre le niveau actuel.
2. Implémenter ma nouvelle solution avec une qualité nettement supérieure (performance, sécurité, lisibilité, robustesse, maintenabilité).
3. Fournir un code qui représente l'état de l'art, surpassant ainsi le reste du projet sans altérer le travail de mes collaborateurs.
